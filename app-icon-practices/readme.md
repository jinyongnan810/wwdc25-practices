## From

https://developer.apple.com/jp/videos/play/wwdc2025/361/

## Steps

0. download [icon composer](https://developer.apple.com/jp/icon-composer/)
1. copy the apple icon template for [figma](https://www.figma.com/community/file/1514335373494164156)
2. create icon in each layers
3. export each layers as svg
4. import each layers in icon composer
5. wrap each layers in separate groups
6. save icon composer project
7. import to xcode and apply
